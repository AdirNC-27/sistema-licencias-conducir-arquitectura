# Atributos de calidad

Los atributos de calidad establecen las características que debe cumplir el Sistema de Licencias de Conducir para funcionar de manera segura, confiable y mantenible.

| ID | Atributo | Requerimiento |
|---|---|---|
| **AC01** | Seguridad | El sistema debe autenticar a los usuarios y limitar las funciones disponibles según el rol y los permisos asignados. |
| **AC02** | Privacidad | Los datos personales, documentos, comprobantes y resultados de evaluaciones deben almacenarse de forma protegida y ser accesibles únicamente por usuarios autorizados. |
| **AC03** | Rendimiento | Las consultas y operaciones habituales deben responder en un tiempo máximo aproximado de tres segundos bajo condiciones normales. |
| **AC04** | Disponibilidad | La plataforma debe estar disponible durante los horarios de atención y permitir la recuperación del servicio ante fallos. |
| **AC05** | Usabilidad | Las interfaces deben utilizar instrucciones claras, estados comprensibles y formularios sencillos para reducir errores de los usuarios. |
| **AC06** | Mantenibilidad | El sistema debe organizarse en módulos separados para permitir cambios en requisitos, pagos, citas, evaluaciones e inteligencia artificial sin afectar innecesariamente otras funciones. |
| **AC07** | Trazabilidad | Las modificaciones de documentos, pagos, evaluaciones y estados deben registrar el usuario responsable, la fecha y la acción realizada. |
| **AC08** | Confiabilidad de la IA | El asistente virtual debe responder utilizando contenidos aprobados y derivar la consulta al gestor cuando no disponga de información suficiente. |
